## 网址导航配置

<br>

暂无可视化操作界面，需要直接修改数据库`zentao.bc_link`表：

<br>


1. `id`：数字格式为：<u>AABCCDDDEE</u>

   + <u>**AA**</u>：区分所属页面；**11** 工作台；**12** 开发工具；**13** 开发环境；**xx** 环境；按需自行修改；

   + <u>**B**</u>：链接在页面上第几列；每个页面有3列超链接；**1** 第一列；**2** 第二列；**3** 第三列；

   + <u>**CC**</u>：链接在列中属于第几段落；每一列可以分为多个段落；

   + <u>**DDD**</u>：具体的链接编号；

   + <u>**EE**</u>：可选项，配合`type=link-more`使用，标记此数据为`AABCCDDD`的下级子项，在点击**更多**之后显示此内容；

<br>

2. `type`：当前数据类型：

   + =**label**：标记当前数据是一个段落。如果`label`字段为空，页面上不显示段落名称；<u>每一个段落，必须有一条=**label**的数据，作为段落数据的父类，否则会出现空指针异常</u>

   + =**label-cpt**：效果同=label，但会将`extra`字段内容渲染成vue组件，进行额外内容显示；
   
   + =**link**：是超链接；

   + =**link-more**：效果同=link，会在名称后面显示更多**按钮**，鼠标点击之后展示下级子项链接信息；

   + =**new-line**：空行，用来分隔排版；

   + =**text**：一段文字描述；

<br>

3. `label`：页面上显示段落内容、或者超链接文本内容；

   + 使用 **{{ }}** 包裹的文本：会被超链接标签替换；例如`商户系统 {{后台}}`，生成的HTML为：`商户系统 <a>后台</a>`，超链接会由点击`后台`触发；

   + =空字符串：当`type=label`时，不显示段落的名称。

<br>

4. `title`：鼠标移入超链接上，显示的title内容，可以为空，默认为`label`字段值；

<br>

5. `linkUrl`：超链接url，多个链接，使用`|`隔开，与`label`中的`{{ }}`位置、数量一一对应：

   + 以 <b>#</b> 开头，在办公平台页面框架内打开链接；

   + 以 <b>$</b> 开头，新开窗口打开链接；

   + 以 <b>@</b> 开头，执行页面上对应的JS函数；

<br>

6. `winTitle`：标签页、新开窗口的标题；

<br>

7. `className`：自定义超链接样式名；

<br>

8. `acs`：当前链接需要的权限编号；如果登录账号没有此权限，接口不会返回此数据；

<br>

9. `desc`：超链接的更多描述、提示；

<br>

10. `extra`：更多定制化的配置，为Json字符串；

<br>

11. `pageId`：所属页面代码：

    + **desktop**：工作台；
    + **devtools**：开发工具；
    + **devenv**：开发环境；
    + **---**：下级子项数据；

<br>

12. `rowId`：有相同**rowId**的数据，会在同一行、两端对齐显示；

<br>

13. `active`：当前数据是否有效；
