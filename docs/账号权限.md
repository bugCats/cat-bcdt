# 账号权限

<br>

`bcdt`可以直接使用禅道数据，与禅道公用一套用户，避免了多个系统的账号割据麻烦；也可以单独独立运行。

如果使用了禅道数据库，则可以直接使用禅道账号登录。同时，如果修改了禅道账号密码、权限，`bcdt`会同步实时更新；<br>
如果未使用禅道，在数据库初始化时，会生成默认的账号/密码：`admin`/`Bugcat6;`，对于账号、密码、权限的操作，都需要通过修改数据库完成。


禅道账号的密码，只是简单将密码进行MD5处理，也可以直接修改：`password = MD5(密码明文)`。


**注**：由于`bcdt`可以访问数据库、查看数据库配置、服务器日志等敏感信息，因此`bcdt`会要求登录密码必须满足指定强度。<br>
在开发测试阶段，可以先屏蔽`cc.bugcat.bcdt.ops.utils.PasswordCheckUtil#checkPassword`关闭密码强度校验；

## 权限运用

权限编号存放于`cc.bugcat.bcdt.ops.constants.Opers`类中。<br>
在Controller方法上添加`@ACS(Opers.xxxx)`注解，表示调用此接口，账号需要xxxx对应的权限编号；<br>
其中以`#`开头的权限，可以通过禅道界面，分配给指定账号；<br>

<br>

### 权限配置：

登录禅道管理账号，进入 `后台` / `人员管理` / `权限` 界面，点击 `新建分组`：
+ 分组名称：该权限的用途描述；约定以`#`开头，表示是用于`bcdt`；
+ 分组描述：该权限的编号，`Opers`类中对应的编号值；同样约定以`#`开头。
+ 用户列表：将权限分配给指定的用户；


<br>

如果是独立数据库运行，需要修改`zt_group`、`zt_usergroup`：

1. 新建权限：

    INSERT INTO `zt_group`(`name`, `role`, `desc`) VALUES ('#团队日报', 'admin', '#1103'); 
 
 
2. 将权限分配给用户：

    INSERT INTO `zt_usergroup`(`account`, `group`) SELECT 'admin' AS 'account', g.id FROM `zt_group` g WHERE g.desc LIKE '#%';
